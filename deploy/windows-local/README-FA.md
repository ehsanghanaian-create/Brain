# SEO Brain — نسخهٔ نصبی ویندوز

این پکیج **کاملاً خودکفا** است: ‏Node.js همراهش هست (نیازی به نصب ندارد) و اگر Python هم روی سیستم نباشد، خودش بی‌صدا نصب می‌کند (بدون نیاز به دسترسی ادمین).

## نصب (فقط یک بار)

1. کل پوشه را هر جا خواستید بگذارید (مثلاً `D:\SEO-Brain`) — مسیر بدون کاراکتر فارسی بهتر است.
2. روی **`INSTALL.bat`** دابل‌کلیک کنید و صبر کنید (بار اول ۵ تا ۱۵ دقیقه: نصب پکیج‌ها و ساخت رابط وب).
3. پایان موفق = پیام سبز «Install finished successfully» + شورت‌کات **SEO Brain** روی دسکتاپ.

اینترنت فقط برای مرحلهٔ نصب لازم است (دانلود پکیج‌های npm/pip).

## استفادهٔ روزانه

| کار | فایل |
|---|---|
| اجرا | **`START.bat`** یا شورت‌کات دسکتاپ — خودش مرورگر را روی `http://localhost:3000` باز می‌کند |
| توقف | **`STOP.bat`** |
| به‌روزرسانی بعد از تغییر کد | دوباره `INSTALL.bat` (سریع‌تر از بار اول) |
| حذف | **`UNINSTALL.bat`** — داده‌هایتان (پوشهٔ `data`) را نگه می‌دارد مگر خودتان تأیید حذف بدهید |

## داده‌ها و تنظیمات

- دیتابیس‌ها در پوشهٔ **`data\`** هستند (`seo.db` و `ads-events.db`). این پکیج با یک نسخهٔ اولیه از داده‌های فعلی شما (پوشهٔ `seed\`) شروع می‌شود.
- تنظیمات backend در فایل **`.env`** ریشه است (بار اول از `.env.example` ساخته می‌شود).
- **کلیدهای AI و رمزهای وردپرس** به‌صورت رمزنگاری‌شدهٔ مخصوصِ همان سیستم ذخیره می‌شوند — بعد از نصب روی سیستم جدید باید یک‌بار در UI دوباره واردشان کنید (سایت‌ها → کارت وردپرس / مدل‌های AI).
- اگر اینترنت‌تان دامنه‌های سایت‌ها یا سرویس‌های گوگل/AI را فیلتر می‌کند، مطابق `docs/DEVELOPMENT-fa.md` بخش پراکسی، ‏`WP_PROXY`/`AI_PROXY` را در `.env` تنظیم کنید.

## اگر مشکلی پیش آمد

- **پنجرهٔ نصب خطا داد:** متن قرمز آخر را بخوانید — معمولاً می‌گوید چه چیزی کم است. لاگ‌های اجرا هم در پوشهٔ `run\` هستند (`backend.err.log` و `frontend.err.log`).
- **«پورت اشغال است»:** یک نسخهٔ دیگر در حال اجراست — اول `STOP.bat`، یا برنامهٔ روی پورت‌های 3000/8000 را ببندید.
- **صفحهٔ مرورگر باز شد ولی خطای اتصال داد:** چند ثانیه صبر کنید و refresh کنید؛ بار اول بالا آمدن کمی طول می‌کشد.
- **Python 3.14 دارید؟** پروژه با آن سازگار نیست — نصب‌کنندهٔ همراهِ پکیج نسخهٔ سازگار (3.12) را کنارش نصب می‌کند؛ چیزی از سیستم‌تان حذف نمی‌شود.
