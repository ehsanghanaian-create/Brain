## Gate پیش از تغییر

1. از VPS، هشت درخواست پیاپی به مبدأ رسمی با host/SNI `salimore.com` برای root، health، types، taxonomies، categories، posts، محصولات و اعتبارسنجی درخواست خالی checkout بدون reset/timeout و با وضعیت مورد انتظار بگذرد.
2. کاندیدای Nginx با upstream مجزای API ساخته شود؛ `nginx -t` و probe روی درگاه آزمایشی HTTPS با نام `api.salimore.com` بگذرد. مسیرهای auth/account همچنان محدود و هیچ cache روی checkout نباشد.

## Gate بعد از تغییر و بازگشت

- از دو resolver مستقل، A رکورد جدید و اعتبار گواهی TLS بررسی شود. REST root، health، دسته‌بندی‌ها، نوشته‌ها و محصولات باید JSON معتبر و ۲xx دهند؛ درخواست خالی checkout باید خطای اعتبارسنجی مورد انتظار بدهد، بدون ایجاد سفارش.
