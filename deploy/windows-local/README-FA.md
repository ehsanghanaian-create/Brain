# SEO Brain — نسخهٔ نصبی ویندوز (آفلاین)

این بسته **کاملاً خودکفا** است و برای نصب به اینترنت نیاز ندارد:

| پیش‌نیاز | وضعیت در بسته |
|---|---|
| Node.js | نسخهٔ پرتابل همراه بسته (نصب نمی‌خواهد) |
| Python 3.12 | نصب‌کنندهٔ رسمی همراه بسته — اگر Python مناسب روی سیستم نباشد بی‌صدا و **بدون دسترسی ادمین** نصب می‌شود |
| کتابخانه‌های بک‌اند | همهٔ wheelها در `runtime\wheels` (نصب با `pip --no-index`) |
| رابط وب | از قبل ساخته شده (`frontend-standalone`) — نه `npm install` لازم است نه build |

## نصب

**راه ۱ — فایل `SEO-Brain-Setup-….exe`:** دابل‌کلیک ← پوشهٔ نصب را انتخاب کنید (پیش‌فرض `D:\SEO-Brain`) ← «نصب». حدود ۳ تا ۶ دقیقه طول می‌کشد.
چون فایل امضای دیجیتال ندارد، ویندوز ممکن است بگوید «Windows protected your PC»؛ روی **More info ← Run anyway** بزنید.

**راه ۲ — فایل `SEO-Brain-Portable-….zip`:** اگر آنتی‌ویروس یا سیاست سازمان اجازهٔ اجرای EXE نمی‌دهد، ZIP را باز کنید و داخل پوشه روی **`INSTALL.bat`** دابل‌کلیک کنید. نتیجه دقیقاً یکی است.

پایان موفق = میان‌بر **SEO Brain** روی دسکتاپ و منوی استارت. نصب مجدد روی نسخهٔ قبلی امن است: پوشهٔ `data` و فایل `.env` دست‌نخورده می‌مانند.

## اتصال Gemini رایگان (۲ دقیقه)

1. اگر در ایران هستید **اول VPN را روشن کنید.** گوگل و Anthropic اتصال مستقیم از ایران را رد می‌کنند. SEO Brain پروکسی محلی VPN شما (v2rayN، Clash، Nekoray، Hiddify …) را **خودکار پیدا می‌کند** (`AI_PROXY=auto` در `.env`)؛ لازم نیست چیزی تنظیم کنید.
2. کلید رایگان بسازید: <https://aistudio.google.com/apikey> ← **Create API key** (با `AIza` شروع می‌شود).
3. در SEO Brain: **تقویم محتوا ← دکمهٔ «کلیدها» ← ردیف Gemini** ← کلید را بچسبانید ← «ذخیره و تست». باید بنویسد «اتصال برقرار است».
4. همان‌جا یک مقالهٔ جدید بسازید و «نوشتن با هوش مصنوعی» را بزنید. مدل پیش‌فرض `gemini-3.5-flash` است (سطح رایگان).

اگر «اتصال برقرار نشد» دیدید: VPN روشن نیست یا پورت محلی‌اش غیرمعمول است — در `.env` مقدار `AI_PROXY` را دستی بگذارید (مثلاً `http://127.0.0.1:10808`) و برنامه را STOP/START کنید.
Claude و Grok هم از همان دیالوگ «کلیدها» وصل می‌شوند ولی حسابشان باید اعتبار (پولی) داشته باشد.

## استفادهٔ روزانه

| کار | فایل |
|---|---|
| اجرا | میان‌بر **SEO Brain** یا `START.bat` — مرورگر روی `http://localhost:3000` باز می‌شود |
| توقف | `STOP.bat` |
| حذف | `UNINSTALL.bat` (یا Settings ← Apps ← SEO Brain) — داده‌ها می‌مانند مگر خودتان تأیید حذف بدهید |

## داده‌ها و تنظیمات

- دیتابیس‌ها در **`data\`** هستند (`seo.db` و `ads-events.db`). اگر بسته پوشهٔ `seed\` داشته باشد، بار اول از روی آن پر می‌شود (نسخه‌ای از داده‌های سازندهٔ بسته).
- تنظیمات backend در **`.env`** ریشه است (بار اول از `.env.example` ساخته می‌شود).
- **کلیدهای AI و رمزهای وردپرس** با رمزنگاریِ مخصوصِ همان سیستم ذخیره می‌شوند — روی سیستم جدید باید یک‌بار در UI دوباره واردشان کنید.
- رابط وب فقط روی همین سیستم (`127.0.0.1`) در دسترس است.

## اگر مشکلی پیش آمد

- **نصب خطا داد:** متن آخر پنجره را بخوانید؛ همان متن در `run\setup.log` ذخیره می‌شود. لاگ‌های اجرا: `run\backend.err.log` و `run\frontend.err.log`.
- **«پورت اشغال است»:** نسخهٔ دیگری در حال اجراست — اول `STOP.bat`، یا برنامهٔ روی پورت‌های 3000/8000 را ببندید.
- **صفحه باز شد ولی خطای اتصال داد:** چند ثانیه صبر و refresh کنید؛ بار اول بالا آمدن کمی طول می‌کشد.
- **Python 3.14 دارید؟** با پروژه سازگار نیست — نصب‌کننده نسخهٔ 3.12 را کنارش نصب می‌کند و چیزی از سیستم حذف نمی‌شود.

## برای توسعه‌دهنده

بسته با `deploy\windows-local\packaging\build-package.ps1` از روی کامیت جاری ساخته می‌شود (`-NoSeed` برای بستهٔ بدون داده). مستند کامل: **`docs/DEVELOPMENT-fa.md`**.
