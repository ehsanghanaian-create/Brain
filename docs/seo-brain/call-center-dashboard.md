# داشبورد، تقویم و کال‌سنتر محلی

این نسخهٔ محلی از رنگ و رفتار تعاملی Gentelella الهام گرفته است و در `frontend/` با React و Next.js پیاده شده است. صفحه‌های جدید `/dashboard/theme`، `/dashboard/users` و `/dashboard/call-center` هستند. تقویم محتوایی در `/dashboard/calendar` ظاهر جدید دارد.

## راه‌اندازی

از ریشهٔ پروژه، `python backend/cli/api.py` و از پوشهٔ `frontend`، `pnpm dev` را اجرا کنید. API هنگام شروع migration شمارهٔ `0020_call_center.sql` را اعمال می‌کند. داده‌های تماس در SQLite محلی قرار می‌گیرند.

## مرکز تماس

- هر تماس می‌تواند سایت، زمان، نام و شماره، وضعیت گارانتی، برند، مدل، منطقه، شرح، اپراتور و وضعیت پیگیری داشته باشد.
- منبع تماس از `سئو`، `ادز`، `مستقیم`، `ارجاع` یا `نامشخص` انتخاب می‌شود و مبنای تشخیص جدا ثبت می‌شود. تماس‌های شیت که شواهد انتساب ندارند `نامشخص` می‌مانند.
- کارت‌ها و نمودارها از تماس‌های ثبت‌شده تغذیه می‌شوند. دادهٔ بازدید ارگانیک/تبلیغاتی و کلیک روی شماره در یک بخش جدا نمایش داده می‌شود و تماس واقعی محسوب نمی‌شود.
- صفحه هنگام باز بودن، هر ۲۰ ثانیه دوباره داده را می‌خواند. گزینهٔ توقف پایش و احترام به تنظیم کاهش حرکت سیستم دارد.
- جدول تماس‌ها در صفحه‌های ۵۰ ردیفی قابل جست‌وجو، فیلتر، ویرایش و خروجی CSV است. فایل CSV همهٔ ردیف‌های مطابق فیلتر فعلی را می‌گیرد. خلاصهٔ نمودارها بر اساس بازهٔ زمانی بالای صفحه محاسبه می‌شود؛ ردیف‌های بدون تاریخ و تاریخ آینده در شمارش بازه‌ای قرار نمی‌گیرند و تعدادشان جدا نمایش داده می‌شود.

## واردکردن شیت

اسکریپت `backend/cli/import-call-center-sheet.py` تب‌های `غیر گارانتی` و `گارانتی` را از فایل XLSX صادرشدهٔ شیت می‌خواند. فایل منبع باید در `data/imports/` یا مسیر محلی دیگر خارج از Git بماند. اجرای معمولی فقط پیش‌نمایش تعداد ردیف‌هاست:

```powershell
python backend/cli/import-call-center-sheet.py data/imports/call-center-source.xlsx
```

پس از تأیید داده و انتخاب تب‌ها، `--apply` داده را وارد می‌کند. کلید یکتای شیت و شمارهٔ ردیف از ورود تکراری جلوگیری می‌کند. ردیف‌های بدون تاریخ معتبر، بدون زمان می‌مانند. هیچ منبع سئو یا ادز از روی نام، خودرو یا شمارهٔ تلفن حدس زده نمی‌شود.

## کاربران و دسترسی

صفحهٔ کاربران فعلاً فهرست اعضا، نقش کاری و وضعیت فعال بودن را برای انتساب اپراتور به تماس‌ها نگه می‌دارد. احراز هویت فعلی SEO Brain بر توکن مشترک API است و نقش‌های این فهرست هنوز مجوز دسترسی جداگانه یا ورود شخصی ایجاد نمی‌کنند. برای استقرار چندکاربره باید ورود، نشست و اعمال مجوز سمت سرور طراحی و فعال شوند.
